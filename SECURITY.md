# Security Policy

This repository takes security seriously. Please follow the Responsible Disclosure process
below if you find a vulnerability.

## Reporting a Vulnerability

Do **not** open a public issue for security problems.

Please report vulnerabilities privately:

1. Go to the repository's **Security** tab.
2. Click **Report a vulnerability** and fill out the form.
3. Include as much detail as you can: affected versions, steps to reproduce, and a
   proof-of-concept or patch suggestion if available.

You will receive an acknowledgment within **2 business days**. We aim to triage the
report and provide an assessment within **7 business days**.

## Expectations

- We will keep you informed of remediation progress.
- We ask you to refrain from public disclosure until there is a fix or the issue is
  assessed, whichever comes first.
